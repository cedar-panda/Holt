## 互相影響的設定

- **只在日常生效**：蛛網記憶（`isSpiderWebEnabled` 要求 daily）、生物鐘（RP 時 `bioclockEnabledF` 直接為 false）、自我註記、語音通話。全域 RP 開啟時，這些開關仍顯示開啟但不會作用。（晏辭審核補正，2026-10-20）

- 摘要是上下文限制、cache 與 RP 投影的共同前置；關掉摘要時，依賴摘要的流程不能假定仍有新摘要可用。
- cache 是否命中由 provider adapter、固定前綴、窗口身分與實際回傳 usage 共同決定；開關本身不是命中證明。
- keep-alive 會保存窗口與提示快照，但 `keepalive_*` 是設備本地運行狀態，不是跨設備備份資料。
- RP 世界書自動整理只在有效 RP 摘要批次達到設定條件時處理；手動世界書仍可獨立修改。
- 工具功能開關既影響 static tool prompt，也影響本輪是否處理對應 action；改 static prompt 可能改變 cache 前綴。

## 看不到效果時先查哪裡

1. 先查模式與窗口 scope。
2. 再查功能開關是否使工具 prompt／processor 同時關閉。
3. 再查資料是否已寫入，但被 `liveStatePart`、有效性或召回上限過濾。
4. cache 與計費最後看 provider usage，不用本地 UI 推測。
