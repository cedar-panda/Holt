# 下次：外部記憶大量匯入

## 目標

讓已經在其他平台或檔案中累積大量記憶的使用者，也能把外部記憶遷入 Holt 使用。

## 核心流程

1. 使用者一次貼上或匯入大量外部記憶。
2. 系統分批交給摘要模型處理，避免單次內容超出上下文或 token 限制。
3. 摘要模型把原始內容整理成結構化記憶：
   - 記憶標號
   - 完整記憶內容
   - 類別
   - 關鍵詞／觸發詞
   - 記憶之間的關聯性
   - 疑似重複或互相衝突的項目
4. 寫入前提供完整預覽，允許修改、合併、排除與重新處理。
5. 使用者確認後才建立記憶條目與蛛網連線；原始匯入來源需保留，方便追溯。

## 實作時要注意

- 大量任務要能顯示進度、暫停後繼續，且失敗時只重試出錯批次。
- 模型不得直接刪除或覆蓋既有記憶；重複與衝突仍進入「待確認」。
- 匯入內容的語言要原樣保留，分類與關鍵詞需跟隨 App 語言或使用者指定語言。
- 標號應是可預覽的匯入批次標號，正式資料庫 ID 仍由本機安全產生。
- 先掃描既有記憶，避免外部匯入再次製造重複條目。

## 完成判定

使用者能把一批外部記憶貼入，看到模型整理後的標號、關鍵詞、重複判定與關聯預覽；確認後，條目和蛛網連線正確建立，未確認內容不會改動既有記憶。
