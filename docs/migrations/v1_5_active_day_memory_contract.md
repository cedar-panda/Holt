# v1.5.0 活躍日記憶遷移契約

資料庫版本：v49。

## 一次性遷移

- 僅在 `oldVersion < 49` 時執行。
- v1.5.0 以前 `archive` 中的記憶全部恢復為 active，並從最低激活程度重新開始：`mention_count = 0`、`clarity = 1.0`、`last_accessed = 升級時間`。
- 升級時已存在的日常蛛網孤島也使用同一個最低激活基準重新起算。
- 無法安全解碼的古老封存快照保留在 archive，不讓單一壞資料阻斷升級，也不丟棄唯一副本。
- v49 之後的升級不可重跑這次復活／重設。

## v1.5.0 之後的衰減

- 一個角色在同一個本地日期至少有一則 user 訊息，即計為一個活躍日；同日多則仍只算一天。
- 日常蛛網記憶只統計日常窗口的活躍日。RP 窗口屬於獨立記憶軌，不消耗日常蛛網記憶的期限。
- 沒有 user 訊息的離線日期完全不計入，因此離線期間真正凍結。
- 記憶建立或最後一次被觸發的當日不列入未提及天數；從下一個活躍日開始累積。
- 孤島達既有 30–90 活躍日恩典期後移入 archive，不做物理刪除。
- 使用者從 archive 手動恢復記憶時，同樣以最低激活程度重新開始，避免剛恢復就再次封存。
